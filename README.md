# Quiz_App

A sleek, responsive multiple-choice quiz application built with vanilla JavaScript. This project demonstrates dynamic DOM manipulation, state management for scoring, and clean UI transitions without the need for external frameworks.

## Features

- **Dynamic UI:** Questions and answer choices are rendered dynamically from a JavaScript data object, making it easy to expand the question bank.
- **Score Tracking:** Real-time logic calculates the total number of correct answers and displays a final tally upon completion.
- **Input Validation:** Prevents the user from skipping questions by ensuring an option is selected before allowing them to click "Submit."
- **Responsive Design:** Optimized for all screen sizes (mobile, tablet, and desktop) using CSS Flexbox and media queries.
- **Restart Functionality:** Includes a seamless "Reload" feature that allows users to reset the state and retake the quiz immediately.

## Tech Stack

- **Frontend:** HTML5, [CSS3](https://developer.mozilla.org) (Custom properties, Flexbox), and [Vanilla JavaScript](https://developer.mozilla.org) (ES6+).
- **Tools:** [VS Code](https://code.visualstudio.com) (IDE), [Git](https://git-scm.com) for version control, and Live Server for development.

## Getting Started / Installation

To get a local copy up and running, follow these simple steps:

1. **Clone the repository**
   ```bash
   git clone https://github.com
   ```

2. **Navigate to the project directory** 
```bash
cd quiz-app
```
3. **Run the app**
Simply open the index.html file in your preferred web browser, or use the Live Server extension in VS Code.
